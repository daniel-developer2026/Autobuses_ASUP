# ASUP Web

Página web estática para Autotransportes Socios Unidos Poblanos.

## Estructura

ASUP-Web/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    ├── autobus_portada.png
    ├── autobus_TienesDuda.png
    └── autobus_villajuarez.png

## Imágenes

Coloca exactamente estas tres imágenes dentro de `images/`:

- autobus_portada.png → Hero principal y tarjeta Zacatlán.
- autobus_TienesDuda.png → tarjeta Huauchinango y sección de contacto.
- autobus_villajuarez.png → tarjeta Villa Juárez y sección de próxima ruta.

## Ejecutar

Abre `index.html` directamente en el navegador o usa Live Server en Visual Studio Code.

No requiere Node.js, npm ni un backend.

## WordPress

La versión está separada en HTML/CSS/JS para facilitar posteriormente su conversión a un tema de WordPress o su reconstrucción en Elementor.
